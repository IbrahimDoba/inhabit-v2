# Inhabit: where we are (2026-09-27)

Read this first in a new session, then `PLAN.md`.

## The app
Inhabit is a habit app. A baby dragon companion lives with you in a garden. Each habit is a plant. Doing habits fills the dragon's energy; a full day sends it on a journey and it returns with diamonds and one gift for the garden. It grows up over weeks. Zero punishment: plants rest, never die; the dragon is never sad.
Inspired by Finch (feel and pacing) and the user's earlier Inhabit docs (concept). Not a copy: no Finch wording, art or names.

## Decisions
- Name: Inhabit. Companion: baby dragon (user names it at hatch). Currency: diamonds. World: garden.
- Fonts: Fredoka (titles, headings, buttons) and Nunito (body), loaded with `useFonts` in the root layout; tokens `Fonts.display/heading/body/bodyLight/bodyBold` in `src/constants/theme.ts`. Each weight is its own family, so use `fontFamily`, never `fontWeight`.
- Colours: lavender #B8A9E8, mint #A9E5C1, warm gold #F2C14E, plum #3B2A4A.
- Tech: Expo SDK 57, React Native, TypeScript, expo-router, pnpm. Data on the phone only in v1.
- Art: Higgsfield (GPT Image stills, Seedance 2.5 animations). Dragon and background are separate layers; dragon clips get transparent backgrounds.
- Work style: plan first, then one small step at a time, show the result, wait for the go-ahead. Generate as few assets as possible.
