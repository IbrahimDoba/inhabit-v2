# Inhabit asset list (draft, 2026-09-27)

Companion: baby dragon. Palette: lavender #B8A9E8, mint #A9E5C1, warm gold #F2C14E, plum #3B2A4A.
Style: soft flat 2D illustration with gentle shading, no outlines or sticker borders. Every piece must be generated from the approved character sheet so the dragon looks the same everywhere.

## Delivery rule

The dragon and the background are separate layers. The garden changes per user (one plant per habit, earned props), so the dragon cannot be baked into the scene.
Dragon clips are generated on a flat solid background, the background is removed, and each clip ships as a transparent animated WebP or PNG sequence. Background loops ship as plain MP4.
